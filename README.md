# Rocket Nation website v0.9

This repository is the static v0.9 website snapshot. GitHub Pages serves `index.html` from the `main` branch root. The Prospects workspace includes all 72,478 company rows and a downloadable Excel workbook with the same company rows, trade summary, and city summary. The former small research set has been reconciled into this single list. See [dataset provenance](DATA-PROVENANCE.md) for the exact inputs, merge decisions, and offline rebuild method.

## Folder map

- Root HTML, CSS and JavaScript: static website pages, interactions and the three calling-list data chunks.
- `assets/`: images, icons and fonts used by the pages.
- `downloads/`: the full calling-list workbook and other website downloads.
- `plan/`: linked business-plan pages.
- `DATA-PROVENANCE.md`: requested explanation of data lineage, replay and continuation. Private raw captures are held in the separate private data repository and the local Rocket Nation `production/` record.

The owner waived the earlier website editorial seal for this v0.9 public preview. Its old receipt remains historical evidence in the local project. Technical and live-page checks govern this preview; the earlier receipt does not certify v0.9.
